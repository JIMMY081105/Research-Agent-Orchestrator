# 楼梯样板选型与独立资产验收

先确认用户说的是建筑楼梯还是攀爬梯；现有 stair 工具不能据名称扩展成 ladder 生成器。仅使用当前已登记且获准的工具、输入与输出目录；缺工具时报告缺口，不把模型生成的任意命令执行为工具。

## 输入

明确房间/楼层身份、真实内边界、层高、单位、upAxis、变换、目标净空与 profile 中允许的 riser/tread/landing 范围。阈值取当前合同，不从历史案例抄数字。

## 选型

- 对当前 profile 允许的每个候选生成或读取真实几何，测量世界坐标 footprint、全体踏面和落地/到达位置；库目录中声明的包围盒只作候选索引。
- 使用实际房间约束比较 footprint 与净空。若无合适候选，返回 NO_FITTING_TEMPLATE 或当前合同同义状态；不缩小身体包络、不静默改层高，也不让模型凭文字声称能放下。
- 模型可从已证实可行的候选中选择并解释数字；后续工具参数由已校验的数据导出，不能从模型返回中直接执行任意路径或命令。
- 在全新、获准的产物目录导出。重开 USD，独立读取网格、单位、坐标、每级高度（含首级/末级）、踏面数量、占地、碰撞语义和路径终点。

## 结论范围

独立楼梯资产合格，不代表已放进完整场景；完整集成还需要墙、门、家具避让、上下层连接、实际运行时物理和机器人行为证据。上楼梯和攀爬梯是不同能力。

输出候选比较、选择理由、真实尺寸、失败候选、产物 hash、回读检查和未验证项。模型执行、另一方审核及工具产物的证据分别记录；stand-in 不能充当真实 CLI 调用。

历史适用边界见 [案例](references/cases.md)。
