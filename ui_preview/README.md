# Scene Control workspace

There is one daily application: **BGV Scene Control** on Desktop or Start, with the window title **BGV Scene Control**. The existing taskbar entry opens the same application. The extra **Scene Control UI Preview** desktop shortcut is preserved in the owned runtime backup and removed from the desktop by `Consolidate`.

Flask + Jinja2 + locally pinned HTMX and small native JavaScript render the approved cyberpunk chat layout inside Windows WebView2. Prompt has the bottom composer and compact GPU chip; Progress has the stage view. Model/effort/permission menus open upward. GPU values in this new layout remain marked DEMO.

## Open

```powershell
& 'E:\Github\Research-Agent-Orchestrator\tools\approved-ui.ps1' -Mode Open
```

Both historical `Start-Preview.ps1` and `Start-Preview.ps1 -Desktop` now launch the same executable/profile/mutex. Reopening focuses the existing window and preserves its unsent draft. There is no second native preview application launched by these entry points.

The configured-machine startup helper checks the loopback UI owner at 127.0.0.1:8878 and starts its presentation server when absent. It refuses an unknown occupied port. It uses a project virtual environment and existing pinned WebView2 files. It does not install or restart a worker, research task, VPN or Windows scheduled task.

## Entry maintenance

```powershell
& 'E:\Github\Research-Agent-Orchestrator\tools\approved-ui.ps1' -Mode Status
& 'E:\Github\Research-Agent-Orchestrator\tools\approved-ui.ps1' -Mode Consolidate
```

Consolidate validates the three owned canonical shortcuts, prepares the one native binary and retires only the exact owned extra desktop preview shortcut, recording its byte hash and backup. It leaves the existing installation/restore receipts intact. `Restore` explicitly restores the older accepted dashboard shortcuts from those original receipts; it is not the normal way to open this layout.

## Execution status

The bounded Task/Standard integration is **deployed on the configured Windows machine**. A missing or paused verified worker is shown as WORKER OFFLINE and leaves Send disabled. The UI automatically observes readiness changes and refreshes actual CLI options without losing the composer. A failed connection never queues a hidden task. It is the same BGV application, not a second product.

The canonical application binary is `.runtime/desktop-ui/app/BGVSceneControl.exe`, with the accepted BGV icon and native AppUserModelID `BGV.SceneControl`. The older preview renderer on 8877 is retained; no new submission is routed to it.
